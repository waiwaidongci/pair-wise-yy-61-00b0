# pair-wise-yy-61 航空器定检工作包执行与放行审阅平台

支持工卡依赖、测量值容差校验、离线暂存、冲突提交提示、分阶段签字、版本差异和放行锁定。超差项目必须由授权人员处理后才能继续。

## 技术栈

React、Fluent UI、Redux Toolkit、React Router、RTK Query、Vite、TypeScript。

## 运行

```bash
npm install
npm run dev
```

访问 `http://localhost:62061`。工卡草稿和审计操作保存在 `localStorage`。

```bash
npm run build
```

## 离线草稿合并

机库网络断断续续时，执行人员可断网继续填写测量值、发现与证据说明，恢复网络后与服务器正式记录合并。合并规则：

- **按工卡版本与字段来源判断，不按后到覆盖**：每个字段记录来源（本地草稿 / 服务器正式记录）。仅一方修改的字段自动合并；同一字段双方都修改时列为冲突项，保留两边值供人工裁决。
- **离线期间结论失效**：同一工卡离线期间被授权、阶段签署或工作包放行时，受影响结论标记为「已失效」，必须重新确认（接受服务器记录或保留为冲突项）后才能写入。
- **失败保留 + 重试幂等**：合并失败后本地草稿与冲突项保留；同一次合并复用同一 `mergeId`，审计记录只写一条，重试不重复。
- **数据迁移**：本地记录带 schema 版本，旧版本数据（无草稿 / 版本字段）首次加载时自动迁移，损坏数据回退默认状态。

合并规划为纯函数（`src/merge.ts`），草稿状态与迁移在 `src/store.ts`，mock 服务器在 `src/api.ts`。
